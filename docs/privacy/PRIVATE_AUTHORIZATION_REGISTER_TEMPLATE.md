# Modèle de registre privé des autorisations

Ce modèle décrit les champs à conserver dans un emplacement privé. Ne jamais remplir ce fichier public avec les noms, signatures ou coordonnées des joueurs.

Pour chaque personne :

- référence interne non publique ;
- catégorie de données autorisée ;
- supports autorisés, dont le Performance Hub public le cas échéant ;
- date et mode de recueil ;
- personne ayant vérifié la preuve ;
- durée ou date de révision ;
- éventuelles limites ;
- date d’un retrait ou d’une modification ;
- emplacement privé du justificatif.

Statuts permis : `À recueillir`, `Vérifiée`, `Limitée`, `Retirée`, `Expirée`.

Une absence de réponse ne vaut jamais autorisation.
